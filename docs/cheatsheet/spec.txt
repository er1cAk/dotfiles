## fzf | peach | fuzzy finder, wired into zsh
{⌃R} | Search all history
{⌃T} | Insert a file path ({Tab} marks several; skips .gitignored files)
{⌥C} | cd into a subdirectory
{**}{Tab} | Fuzzy-complete any argument: <code>vim **</code>, <code>cd **</code>, <code>ssh **</code>, <code>kill -9 **</code>
### Inside the picker
{↑} {↓} | Move (also {⌃J} {⌃K}); {↩} picks, {Esc} cancels
> Search syntax: <code>'exact</code> <code>^prefix</code> <code>suffix$</code> <code>!exclude</code>, and <code>a | b</code> for either.

## zoxide | teal | jump to directories you use
{z lois} | Best-ranked directory matching "lois"
{z lois front} | More words narrow it down
{zi lois} | Choose among the matches with fzf
{z -} | Back to the previous directory
> Learns from every <code>cd</code>; frequent and recent directories rank first.

## Prompt | yellow | reading starship's two lines
@@PROMPT@@
{❯} | <span class=ok>green</span>: last command succeeded; <span class=bad>red</span>: it failed
{?} {!} {+} | Untracked / modified / staged files
{✘} {»} {=} | Deleted / renamed / conflicted
{$} | A stash exists
{⇡3} {⇣3} | Commits ahead of / behind upstream
<b>REBASING 2/5</b> | Unfinished rebase, merge, cherry-pick or bisect
> The path starts at the repo root. <code>user@host</code> appears only over SSH. Node, Python (with venv) and Go versions appear only in projects that use them.

## git | red | what the config does for you
<b>Identity</b> | Repos under <code>~/Work</code> commit with the work email, everything else with the personal one
<b>Diffs</b> | <code>git diff</code>, <code>show</code>, <code>log -p</code> and <code>add -p</code> render through diff-so-fancy
<b>Fixups</b> | <code>git commit --fixup &lt;sha&gt;</code>, then <code>git rebase -i &lt;base&gt;</code>: autosquash lines them up
<b>Pull</b> | Fast-forward only: it never creates a surprise merge commit
