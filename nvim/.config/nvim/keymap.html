Worth knowing

Images need the browser

Alacritty implements neither sixel nor the kitty graphics protocol, so images can't draw in the terminal. Spc m p opens the preview where images and mermaid diagrams both render.

Go uses gofmt, not gofumpt

Your repos enable gofmt + goimports in .golangci.yml. gofumpt is stricter and would quietly reformat beyond that, adding unrelated noise to reviews.

gr, K and ; are unmapped on purpose

Neovim 0.11+ owns gr*. Mapping gr makes it both a mapping and a prefix, so every built-in behind it waits out timeoutlen.

Keep the Mono in the font name

In the plain Nerd Font family, icon ink is ~155% of a cell while advancing only one — icons bleed and the cursor clips them. The Mono variants scale icons to exactly one cell.

Format on save is on

Turn it off for the session with Spc u f, or per-buffer with :FormatDisable!. :FormatEnable brings it back.

Check before you commit

Editing ~/.config/nvim edits the dotfiles repo directly — stow symlinks it. Run ~/dotfiles/check.sh to assert all 35 invariants still hold.
